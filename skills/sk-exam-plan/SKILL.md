# 구현 계획

이 파일은 원본과 별개로 작성한 시험용 연결 스킬이다. 원본을 실제로 읽고 허용된 절차를 적용한다. 원본 전체 런타임 실행과 구분한다.

## 먼저 읽을 파일

1. 형제 폴더 `../sk-ai-exam-operator/references/skill-routing.md`의 공통 실행 계약.
2. 형제 운영 스킬의 `upstream/superpowers/skills/writing-plans/SKILL.original.md` 원본 전체. 아래 지원 문서의 경로는 해당 프로젝트의 `upstream/superpowers/` 기준이다.

최초 적용에는 위 원본을 읽는다. 동일 버전 원본과 공통 계약이 현재 문맥에 남아 있는 재진입에는 재사용하고 필요한 절만 확인한다. 문맥을 잃거나 파일이 바뀌면 다시 읽고, 실제 최초 읽기와 재사용을 구분한다.

원본이 없거나 잠금 해시가 맞지 않으면 원본 적용 성공으로 표시하지 않는다. 문제를 짧게 알리고 운영 스킬의 기본 도구로 가능한 작업을 이어간다. 준비되지 않은 명령·별도 런타임을 설치하지 않는다.

## 현재 단계의 적용

- 원본의 File Structure, Task Right-Sizing, Interfaces, Self-Review를 적용한다. `02_requirements.md`에 목표·근거·범위·파일·의존 순서·완료 조건·검사 명령을 담은 짧은 실행 계획을 추가한다. 기존 지정 계획 파일이 있으면 그 위치를 링크한다.
- 첫 사용자 흐름 하나가 실행되도록 작업을 자르고 중요한 업무 예외를 어느 작업의 검사로 입증할지 정한다. 확인하지 않은 함수·경로·예상 출력을 실제 사실로 적지 않는다.
- 기본 실행 방식은 현재 제공 작업공간에서의 inline 실행이다. 사용자가 이 운영 흐름의 구현을 이미 요청했다면 계획 링크와 핵심 선택을 보여 준 뒤 `sk-exam-implement`로 계속한다. 업무 정책의 공백만 질문한다.
- 원본의 매 단계 커밋·별도 worktree·추가 승인 대기·새 세션은 시험 기본 의무가 아니다. 기존 과제 실행 경로를 우선하며 모델·런타임·작업공간을 바꾸지 않는다.

## 결과 연결

현재 사용한 스킬·원본 경로·원본 적용 범위·중요 생략을 `05_verification.md`의 스킬 적용 기록에 짧게 남긴다. 세 세션 운영이면 세션 1은 `exam-notes/10_work_log.md`, 세션 2는 `exam-notes/20_review.md`에 같은 내용을 남기고 세션 3이 01~05로 옮긴다. 파일을 읽은 사실과 검사 실행·기능 완료는 별개다. 끝나면 운영 스킬로 돌아가 남은 시간과 실제 상태에 맞는 다음 한 작업을 이어간다.
