# AI 제안과 실제 판단

_빈 기록 양식 · 참가자가 실제 밝힌 선택과 이유만 기록 · 판단 이유 대필 금지_

---

## 📋 결정 기록

선택은 채택 / 수정 후 채택 / 기각 / 보류로 구분한다. 제안이 맞으면 검증 후 채택한다. 거절 횟수를 만들지 않는다.

| D ID | 당시 문제·제약 | 실제 AI 제안 | 내 실제 선택 | 내가 실제 밝힌 이유 | 영향·반례·작은 대안 | Q·F·E·T 연결 | 재검토 조건 |
|---|---|---|---|---|---|---|---|

## 🔍 중요한 제안을 검토하는 질문

1. 어떤 실제 실패를 해결하는가?
2. 어떤 요구·답변·코드·관찰이 근거인가?
3. 정상 동작, 데이터 의미, 상태·저장에 미치는 영향은?
4. 제안이 틀리는 최소 반례는?
5. 더 작은 수정으로 해결할 수 있는가?
6. 무엇을 실행하면 효과와 회귀 여부를 확인할 수 있는가?

## 🧩 도구 사용 기록

| 도구·Skill·원본 | 실제 사용 범위 | 정식 실행 또는 원칙 참고 | 확인한 실행 결과·한계 |
|---|---|---|---|

다운로드, Skill 인식, 실제 실행을 구분한다. 외부 워크플로의 일부만 참고했으면 전체 실행 완료라고 쓰지 않는다.
