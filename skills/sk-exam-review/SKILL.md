# 통합 코드 검토

이 파일은 원본과 별개로 작성한 시험용 연결 스킬이다. 원본을 실제로 읽고 허용된 절차를 적용한다. 원본 전체 런타임 실행과 구분한다.

## 먼저 읽을 파일

1. 형제 폴더 `../sk-ai-exam-operator/references/skill-routing.md`의 공통 실행 계약.
2. 형제 운영 스킬의 `upstream/gstack/review/SKILL.original.md` 원본 전체. 아래 지원 문서의 경로는 해당 프로젝트의 `upstream/gstack/` 기준이다.

원본이 없거나 잠금 해시가 맞지 않으면 원본 적용 성공으로 표시하지 않는다. 문제를 짧게 알리고 운영 스킬의 기본 도구로 가능한 작업을 이어간다. 준비되지 않은 명령·별도 런타임을 설치하지 않는다.

## 현재 단계의 적용

- 원본과 `review/checklist.md`를 읽고 실제 변경 전체와 요구·예외 목록을 대조한다. 계획 누락 점검에는 `review/sections/plan-completion.md`를 읽는다.
- 관련 변경에 따라 `review/specialists/state-machines.md`, `api-contract.md`, `testing.md`, `data-migration.md` 등 실제 필요한 전문 검토 문서를 읽는다. 전문가 에이전트를 실행하지 않았다면 문서를 활용한 자기 검토로 표시한다.
- Git이 있으면 로컬 diff와 미추적 파일을 함께 확인하고, 없으면 변경한 파일과 기존 관찰을 대조한다. main 브랜치이거나 원격 PR이 없다고 검토를 건너뛰지 않는다.
- 원격 fetch·gh/glab API·Greptile 댓글·telemetry·외부 AI·브라우저·review army·merge/push는 실행하지 않는다. 원본의 PR 리뷰 gate와 로그는 완료 주장 대상에서 제외하고 검토한 코드·발견·미검증을 기록한다.
- 심각한 결함은 원인을 확인해 수정·재검사한다. 범위 확장이나 낮은 가치의 리팩터링은 남은 시간과 영향으로 판단한다. 발견 없는 영역까지 통과로 만들지 않는다.

## 결과 연결

현재 사용한 스킬·원본 경로·원본 적용 범위·중요 생략을 `05_verification.md`의 스킬 적용 기록에 짧게 남긴다. 파일을 읽은 사실과 검사 실행·기능 완료는 별개다. 끝나면 운영 스킬로 돌아가 남은 시간과 실제 상태에 맞는 다음 한 작업을 이어간다.
