# AI 제안 심사

이 파일은 원본과 별개로 작성한 시험용 연결 스킬이다. 원본을 실제로 읽고 허용된 절차를 적용한다. 원본 전체 런타임 실행과 구분한다.

## 먼저 읽을 파일

1. 형제 폴더 `../sk-ai-exam-operator/references/skill-routing.md`의 공통 실행 계약.
2. 형제 운영 스킬의 `upstream/superpowers/skills/receiving-code-review/SKILL.original.md` 원본 전체. 아래 지원 문서의 경로는 해당 프로젝트의 `upstream/superpowers/` 기준이다.

원본이 없거나 잠금 해시가 맞지 않으면 원본 적용 성공으로 표시하지 않는다. 문제를 짧게 알리고 운영 스킬의 기본 도구로 가능한 작업을 이어간다. 준비되지 않은 명령·별도 런타임을 설치하지 않는다.

## 현재 단계의 적용

- 원본의 이해→코드·요구와 대조→평가→답변 또는 수정 순서를 적용한다. 제안자의 권위나 동의만으로 수정하지 않는다.
- 제안별 실제 문제·근거·데이터와 상태 영향·최소 반례·작은 대안·검증 방법을 대조한다. 잘못된 제안은 근거와 함께 수정·기각하고 맞는 제안은 검증 가능한 범위로 구현한다.
- `04_decisions.md`에는 실제 AI 제안과 참가자가 실제 밝힌 채택·수정·기각·보류 및 이유만 기록한다. 이유가 없으면 참가자 이유 미기재로 둔다. AI의 평가 근거는 AI 제안으로 별도 표시한다.
- 모든 사소한 구현 선택에 승인을 요구하지 않는다. 참가자 판단이 필요한 중요한 제안과 이미 승인된 가역적 구현을 구분한다.

## 결과 연결

현재 사용한 스킬·원본 경로·원본 적용 범위·중요 생략을 `05_verification.md`의 스킬 적용 기록에 짧게 남긴다. 파일을 읽은 사실과 검사 실행·기능 완료는 별개다. 끝나면 운영 스킬로 돌아가 남은 시간과 실제 상태에 맞는 다음 한 작업을 이어간다.
