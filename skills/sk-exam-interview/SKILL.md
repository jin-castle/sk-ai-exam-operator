# 업무 인터뷰

이 파일은 원본과 별개로 작성한 시험용 연결 스킬이다. 원본을 실제로 읽고 허용된 절차를 적용한다. 원본 전체 런타임 실행과 구분한다.

## 먼저 읽을 파일

1. 형제 폴더 `../sk-ai-exam-operator/references/skill-routing.md`의 공통 실행 계약.
2. 형제 운영 스킬의 `upstream/ouroboros/skills/interview/SKILL.original.md` 원본 전체. 아래 지원 문서의 경로는 해당 프로젝트의 `upstream/ouroboros/` 기준이다.

최초 적용에는 위 원본을 읽는다. 동일 버전 원본과 공통 계약이 현재 문맥에 남아 있는 재진입에는 재사용하고 필요한 절만 확인한다. 문맥을 잃거나 파일이 바뀌면 다시 읽고, 실제 최초 읽기와 재사용을 구분한다.

원본이 없거나 잠금 해시가 맞지 않으면 원본 적용 성공으로 표시하지 않는다. 문제를 짧게 알리고 운영 스킬의 기본 도구로 가능한 작업을 이어간다. 준비되지 않은 명령·별도 런타임을 설치하지 않는다.

## 현재 단계의 적용

- 원본의 `Path B: Fallback (No MCP Server)`와 함께 `src/ouroboros/agents/socratic-interviewer.md`를 읽는다. 종료·규칙 요약 시 `seed-closer.md`도 읽는다. 파일은 이미 포함돼 있으므로 `uvx`나 MCP를 설치하지 않는다.
- 최근 실제 사례, 다음 의사결정, 가장 큰 오판을 먼저 확인한다. 답이 코드·정책·기대 결과를 바꾸는 질문부터 한 번에 한 가지씩 제안하고 참가자가 초안의 사실·맥락·표현을 직접 검토한 뒤 담당자에게 직접 묻도록 한다.
- 모순·가정·미확인을 짧은 ledger로 `01_domain.md`에 기록한다. 이해한 조건→처리→예외→성공 기준을 재진술한다. 원본의 정교화·종료 점검을 이 기록에 적용한다.
- 원본의 ambiguity 점수·최소 라운드·완전한 Seed 생산을 시험의 공식 배점이나 의무로 만들지 않는다. 확인되지 않은 업무 정책이 큰 오판을 만들면 해당 부분은 임의 확정하지 않고 독립 작업을 계속한다.

## 결과 연결

현재 사용한 스킬·원본 경로·원본 적용 범위·중요 생략을 `05_verification.md`의 스킬 적용 기록에 짧게 남긴다. 파일을 읽은 사실과 검사 실행·기능 완료는 별개다. 끝나면 운영 스킬로 돌아가 남은 시간과 실제 상태에 맞는 다음 한 작업을 이어간다.
